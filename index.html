Case Study 1 — Simplifying Financial Infrastructure

Context

Blockchain-based payments platform for financial institutions.

Problem

Bank stakeholders struggled to understand how the system worked. Existing materials were too technical and not usable in real conversations.

Approach

Reframed as an information design problem — reduce cognitive load and structure content for clarity.

Solution

Developed a modular storytelling system using visual-first explanations and structured narrative flows.

Trade-offs

Prioritised clarity over completeness. Simplified technical details to improve usability.

Impact

Improved client understanding and reduced friction in GTM conversations. Used in major bank engagements.
